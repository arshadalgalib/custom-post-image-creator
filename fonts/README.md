# Bundled Unicode fonts

The browser renderer loads these bundled families with the FontFace API; the fonts remain Unicode and are not converted to a legacy encoding.

- `NotoSerifBengali-Regular.ttf` — Noto Serif Bengali; Noto Project Authors, SIL Open Font License 1.1 (`OFL-notoserifbengali.txt`).
- `NotoSansBengali-Regular.ttf` — Noto Sans Bengali; Noto Project Authors, SIL Open Font License 1.1 (`OFL-notosansbengali.txt`).
- `HindSiliguri-Regular.ttf` — Hind Siliguri; Indian Type Foundry, SIL Open Font License 1.1 (`OFL-hindsiliguri.txt`).

The corresponding license notices are included alongside the font files. Template Manager exposes the bundled families; unbundled legacy font names are not promised to render consistently in browser Canvas.
