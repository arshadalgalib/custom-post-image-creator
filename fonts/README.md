# Bundled Bengali fonts

The plugin ships these fonts and uses their filenames to register a stable Fontconfig/Pango family:

- `NotoSerifBengali-Regular.ttf` — Noto Serif Bengali
- `NotoSansBengali-Regular.ttf` — Noto Sans Bengali
- `HindSiliguri-Regular.ttf` — Hind Siliguri

Optional legacy font support is retained when administrators add `SolaimanLipi.ttf` or `SiyamRupali.ttf` to this directory. Those optional families appear in Template Manager only when the corresponding file exists.
